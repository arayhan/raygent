# 0-step-03-data-round-trip

Connect the stack end-to-end with a minimal data round-trip.

## Goal

Verify that data can be written through the user interface/client and persisted such that refreshing the page or restarting the client retrieves the saved record. (Visual styling is not required to be polished at this stage.)

## Deliverables

- A minimal form or mutation path that writes a single record
- A view or query path that reads the record back after refresh

## Acceptance Criteria

- Write one record through the UI/form.
- Refresh the page / re-query; verify the saved record appears.
